# Frontend Assignment 2 - Flexbox & Grid

## Description

This project is a solution to Assignment 2 (Flexbox & CSS Grid). It includes 5 pages built with plain HTML and CSS, connected through a shared navigation bar:

- **index.html** - Home page
- **cards.html** - Task 1: Card Row (Flexbox)
- **layout.html** - Task 2: Page Layout with Grid Areas (CSS Grid)
- **gallery.html** - Task 3: Image Gallery (CSS Grid)
- **portfolio.html** - Task 4: Portfolio Page (Flexbox + Grid combined)

All pages share one stylesheet: **style.css**.

## How to run

1. Clone or download this repository.
2. Open `index.html` in any browser.
3. Use the navigation bar at the top to move between pages.
